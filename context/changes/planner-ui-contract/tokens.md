# Token values: React Flow on the tokens (C2)

React Flow 12.12.0 is themed through its `--xy-*` custom properties. Every rule in `node_modules/@xyflow/react/dist/style.css` reads `var(--xy-NAME, var(--xy-NAME-default))`, and the library only ever sets the `-default` names, so the overrides set the plain `--xy-NAME` on `.react-flow` in `src/styles/global.css` (unlayered, after the React Flow import). Every value is a `var(--token)` reference to an existing role in `:root`; no `:root` value was added. Arrowheads follow the edge colour because `Diagram.tsx` passes `defaultMarkerColor={null}`, which drops React Flow's inline `#b1b1b7` stroke and fill so `.react-flow__arrowhead polyline` (`style.css:193-198`) reads `--xy-edge-stroke`.

Contrast figures use WCAG 2 relative luminance; for achromatic OKLCH (C = 0) the linear luminance is Y = L³. `--muted-foreground` `oklch(0.556 0 0)` gives Y = 0.172 and `--muted` `oklch(0.97 0 0)` gives Y = 0.913, so (0.913 + 0.05) / (0.172 + 0.05) = 4.34:1. The old `#b1b1b7` on the white page was 2.13:1.

Not mapped because the view does not draw them: connection line (`nodesConnectable={false}`), minimap, node defaults (Task, START and FINISH are custom nodes styled with token classes), handles, selection box, edge labels, resize controls.
